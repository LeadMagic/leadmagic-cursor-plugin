# Account intelligence (supporting)

Not a front-door skill. After search, if the user wants company context on **selected** accounts:

- Light brief → `research_account`
- Combined research + competitors + tech + jobs → `account_intel` (preview cost first)
- Open roles only → `find_jobs` / `search_jobs`
- Competitors or technographics only → those advertised tools

Prefer `company_domain`. Return tool facts only. Do not invent traffic or capabilities LeadMagic does not expose.
