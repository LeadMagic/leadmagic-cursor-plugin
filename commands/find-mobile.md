# Find a professional mobile number

OAuth MCP `https://mcp.leadmagic.io/mcp` — one browser sign-in, no keys.

1. Collect a **work email** or **B2B profile URL**. Confirm the user is authorized to contact this person.
2. Preview cost if available, then run MCP `find_mobile_number` once.
3. Report the tool result. Treat the number as confidential business data. Do not scrape or guess.
